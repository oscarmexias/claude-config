# Animate a 3D Box Geometry with Framer Motion 3D

Source: https://github.com/grx7/framer-motion/blob/main/packages/framer-motion-3d/README.md

This snippet demonstrates how to apply a basic animation to a 3D box geometry component using Framer Motion 3D within a React Three Fiber setup. It illustrates a simple animation along the x-axis. This functionality requires the `framer-motion-3d` library and a React Three Fiber environment.

```jsx
<motion.boxGeometry animate={{ x: 0 }} />
```

# Activation Protocol and Commands

ACTIVATION PROTOCOL:
When a UI/design decision comes up:
1. Read what the user is building and which project is active.
2. Rank the top 3 skills relevant RIGHT NOW (no more than 3).
3. One line per skill explaining why it applies here.
4. Offer to activate the top one immediately.

HOW TO ACTIVATE A SKILL:
- Say the skill name as a slash command: /frontend-design, /awwwards-animations, /ui-animation
- Or tell Claude explicitly: 'use the [skill-name] skill'
- fixing-motion-performance works best scoped to a file: /fixing-motion-performance src/components/Hero.tsx
- component-scout: /component-scout 'query' 'project'

TRIGGER WORDS for ui-arsenal:
UI, design, animation, make it look better, hero section, layout, starting frontend, design review, component, landing page, dashboard, any visual output question.

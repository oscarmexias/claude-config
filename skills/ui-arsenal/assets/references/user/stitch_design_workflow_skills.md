# Stitch Design Workflow Skills

STITCH DESIGN WORKFLOW — for designing before coding. Requires stitch MCP connected (check: stitch: Connected in claude mcp list):

10. stitch-design (new) — Entry point for Stitch MCP. Generates screens from text prompts. Activate when designing new screens visually before coding.
11. design-md (new) — Generates .stitch/DESIGN.md design tokens. Activate at project start when using Stitch.
12. stitch-loop (new) — Autonomous iterative builder with Stitch. Activate for building multiple pages autonomously.

UI COMPONENT DISCOVERY:
13. component-scout (installed) — Finds components from 21st.dev, Aceternity, Magic UI, shadcn. Activate before building any UI component from scratch.

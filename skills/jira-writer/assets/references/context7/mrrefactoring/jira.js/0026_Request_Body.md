# Request Body

- **jql** (string) - Optional - The JQL query string (alternative to query parameter).
- **startAt** (integer) - Optional - The index of the first issue to return.
- **maxResults** (integer) - Optional - The maximum number of issues to return per page.
- **fields** (array) - Optional - A list of fields to include in the search results.
- **fieldsByKeys** (boolean) - Optional - Whether to return fields by their keys.
- **expand** (array) - Optional - Additional information to expand in the response.

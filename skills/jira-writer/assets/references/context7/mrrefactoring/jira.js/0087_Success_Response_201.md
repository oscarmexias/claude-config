# Success Response (201)

- **id** (integer) - The ID of the newly created sprint.
- **self** (string) - The URL of the newly created sprint.
- **name** (string) - The name of the sprint.
- **state** (string) - The current state of the sprint ('future', 'active', 'closed').
- **startDate** (string) - The start date of the sprint.
- **endDate** (string) - The end date of the sprint.
- **originBoardId** (integer) - The ID of the board the sprint belongs to.
- **goal** (string) - The goal of the sprint.

# Query Parameters

- **startAt** (integer) - Optional - The index of the first notification scheme to return.
- **maxResults** (integer) - Optional - The maximum number of notification schemes to return per page.

- **name** (string) - Required - The name of the notification scheme.
- **description** (string) - Optional - The description of the notification scheme.
- **notificationSchemeEvents** (array) - Optional - A list of events and their associated recipients.

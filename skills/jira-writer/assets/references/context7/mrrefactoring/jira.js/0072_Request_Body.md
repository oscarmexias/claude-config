# Request Body

- **type** (object) - Required - The type of link.
  - **name** (string) - Required - The name of the link type (e.g., 'Blocks').
- **inwardIssue** (object) - Required - Details of the inward issue.
  - **id** (string) - Required - The ID of the inward issue.
- **outwardIssue** (object) - Required - Details of the outward issue.
  - **id** (string) - Required - The ID of the outward issue.

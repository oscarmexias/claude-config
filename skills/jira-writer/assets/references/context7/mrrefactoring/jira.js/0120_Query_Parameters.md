# Query Parameters

- **expand** (string) - Optional - Expands specific fields in the project details (e.g., `lead`, `projectTypeKey`, `avatarUrls`).
- **startAt** (integer) - Optional - The index of the first project to return (0-based).
- **maxResults** (integer) - Optional - The maximum number of projects to return per page.
- **query** (string) - Optional - Filters projects by name or key.
- **projectTemplateKey** (string) - Optional - Filters projects by template key.
- **projectTypeKey** (string) - Optional - Filters projects by type.
- **includeArchived** (boolean) - Optional - Whether to include archived projects.

# Success Response (200)

- **id** (string) - The ID of the priority.
- **name** (string) - The name of the priority.
- **statusColor** (string) - The color associated with the priority.

```json
[
  {
    "id": "10000",
    "name": "Highest",
    "statusColor": "#de350b"
  }
]

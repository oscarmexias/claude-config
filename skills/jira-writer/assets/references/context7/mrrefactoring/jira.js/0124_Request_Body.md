# Request Body

- **key** (string) - Required - The project key (e.g., 'NEWPROJ').
- **name** (string) - Required - The project name (e.g., 'New Project').
- **description** (string) - Optional - A description for the project.
- **leadAccountId** (string) - Required - The account ID of the project lead.
- **projectTypeKey** (string) - Required - The type of the project (e.g., 'software', 'service_desk').
- **projectTemplateKey** (string) - Required - The key of the project template to use (e.g., 'com.pyxis.greenhopper.jira:gh-scrum-template').

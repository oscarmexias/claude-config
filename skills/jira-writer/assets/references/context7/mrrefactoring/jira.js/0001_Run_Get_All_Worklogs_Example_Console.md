# Run Get All Worklogs Example (Console)

Source: https://github.com/mrrefactoring/jira.js/blob/master/examples/README.md

Executes the example script to retrieve all worklogs associated with a Jira task. This involves creating a task, adding a worklog, and then fetching all recorded worklogs for that task. A project must exist prior to running this.

```console
npm run getAllWorklogs
```

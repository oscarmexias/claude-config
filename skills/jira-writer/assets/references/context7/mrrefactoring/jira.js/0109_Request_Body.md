# Request Body

- **url** (string) - Required - The URL of the remote resource.
- **title** (string) - Required - The title of the remote link.
- **application** (object) - Optional - Information about the application providing the link.
  - **name** (string) - Required - The name of the application.
- **object** (object) - Optional - Details about the linked object.
  - **title** (string) - Required - The title of the object.
  - **url** (string) - Required - The URL of the object.

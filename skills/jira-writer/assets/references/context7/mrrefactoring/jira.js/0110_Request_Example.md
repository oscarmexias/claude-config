# Request Example

```json
{
  "url": "https://example.com/repo/123",
  "title": "Repository Branch",
  "application": {
    "name": "GitHub"
  }
}
```

- **id** (string) - The ID of the remote link.
- **url** (string) - The URL of the remote resource.
- **title** (string) - The title of the remote link.

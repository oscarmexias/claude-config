# Setup Jira Credentials (TypeScript)

Source: https://github.com/mrrefactoring/jira.js/blob/master/examples/README.md

Specifies the Jira host, email, and API token for authentication. These credentials are required by the jira.js library to make API requests. Ensure you replace the placeholder values with your actual Jira instance details.

```typescript
const host = 'https://your-domain.atlassian.net';
const email = 'YOUR_EMAIL';
const apiToken = 'YOUR_API_TOKEN';
```

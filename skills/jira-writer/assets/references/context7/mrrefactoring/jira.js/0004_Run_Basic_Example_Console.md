# Run Basic Example (Console)

Source: https://github.com/mrrefactoring/jira.js/blob/master/examples/README.md

Executes the basic example script, which creates a new Jira project and task. If a project already exists, it adds a task to the first found project. Otherwise, it creates a new project named 'My Project' with key 'PROJECT' and then adds a task.

```console
npm run basic
```

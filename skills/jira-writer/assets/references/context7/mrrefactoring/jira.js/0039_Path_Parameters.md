# Path Parameters

- **fieldId** (string) - Required - The ID of the custom field.

- **name** (string) - Required - The name of the context.
- **description** (string) - Optional - The description of the context.
- **projectIds** (array) - Optional - A list of project IDs to associate with the context.
- **issueTypeIds** (array) - Optional - A list of issue type IDs to associate with the context.

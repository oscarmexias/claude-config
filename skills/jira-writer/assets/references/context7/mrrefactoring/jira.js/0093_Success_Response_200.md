# Success Response (200)

- **id** (string) - The ID of the field.
- **name** (string) - The name of the field.
- **schema** (object) - The schema definition of the field.

```json
[
  {
    "id": "customfield_10000",
    "name": "Story Points",
    "schema": {
      "type": "number",
      "custom": "com.pyxis.greenhopper.jira:gh-numeric-field"
    }
  }
]
```

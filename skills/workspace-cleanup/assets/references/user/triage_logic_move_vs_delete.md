# Triage logic: move vs delete for stray root files

When auditing workspace root, classify each non-whitelisted file:

**MOVE** — file has clear destination:
- Filename starts with a project prefix that matches an existing subdirectory → move into that dir
- Examples: `quinielazo-*.json` → `quinielazo-clone/`, `sbs-export.csv` → `SBS/`

**DELETE** — file is disposable:
- Agent-generated analysis outputs: `*-snapshot.md`, `*-analysis.json`, `*-info.json`, `*-links.json`, `*-elements.json`, `*-style*.json`
- Images/media at root: `*.png`, `*.jpg`, `*.jpeg`, `*.gif`, `*.webp`
- Temp/editor artifacts: `*.tmp`, `*.temp`, `*.bak`, `*.swp`
- Empty autogenerated files: CHANGELOG.md under 200 bytes, etc.

**FLAG for user** — ambiguous, ask before acting:
- Certificates: `*.crt`, `*.pem`, `*.key` → could be needed, confirm unused before deleting
- `.agentrules` → workspace-level agent config, keep unless user says otherwise
- Any file over 50KB that doesn't match known patterns → don't assume, ask

**KEEP** — always:
- CLAUDE.md, README.md, PROJECT-JOURNAL.md, OSCAR-VOICE-JOURNAL.md
- .gitignore, .gitattributes, package.json (if workspace-level)
- All directories (never remove dirs without explicit instruction)

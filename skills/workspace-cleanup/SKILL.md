# workspace-cleanup

Smart root-level auditor. Not just image cleanup — full triage of everything that shouldn't be at the workspace root, with a move-vs-delete recommendation for each file.

## Invocation

```
/user:workspace-cleanup
```

Operates on `$PWD` (current working directory), depth 1 only. Never recurses.

---

## What belongs at the workspace root (never touch these)

| File/Pattern | Why it belongs here |
|-------------|-------------------|
| `CLAUDE.md` | Workspace instructions |
| `README.md` | Workspace overview |
| `PROJECT-JOURNAL.md` | Cross-project session log |
| `OSCAR-VOICE-JOURNAL.md` | Narrative journal (global) |
| `CHANGELOG.md` (if >200B) | Workspace changelog |
| `.gitignore`, `.gitattributes` | Git config |
| `.agentrules` | Agent configuration |
| `package.json`, `tsconfig.json` | Only if workspace-level |
| Named project directories | `SBS/`, `Kinez/`, `CVs/`, etc. |
| Hidden config dirs | `.claude/`, `.gsd-t/`, `.git/`, `_bmad/` |

---

## What does NOT belong at root — triage logic

### Category 1: Project-prefixed files → MOVE
Any file whose name starts with a known project name prefix belongs inside that project's folder.

Detection: scan root files, check if filename starts with any existing subdirectory name (case-insensitive).

Examples:
- `quinielazo-*.json` → move to `quinielazo-clone/` (or `_archive/`)
- `madame-flihan-analysis.md` → move to `Madame Flihan/`
- `sbs-export.csv` → move to `SBS/`

### Category 2: Analysis/scraping outputs → DELETE (confirm first)
Files clearly generated by automated tools during a session:
- `*-snapshot.md`, `*-analysis.json`, `*-info.json`, `*-links.json`
- `*-elements.json`, `*-style*.json`, `*-audit*.md`

These are agent leftovers. No value keeping them at root.

### Category 3: Images and media → DELETE
- `*.png`, `*.jpg`, `*.jpeg`, `*.gif`, `*.webp`, `*.svg` at root
- Screenshots, exports, deliverables accidentally saved here

### Category 4: Certificates and keys → MOVE or DELETE
- `*.crt`, `*.pem`, `*.key`, `*.p12` → flag with warning
- `obsidian-local-rest-api.crt` → move to `~/.config/obsidian/` or delete if expired/unused

### Category 5: Temp and editor artifacts → DELETE
- `*.tmp`, `*.temp`, `*.bak`, `*.swp`, `*.DS_Store`

### Category 6: Tiny/empty files → DELETE
- `CHANGELOG.md` under 200 bytes → likely autogenerated empty shell, delete

---

## Behavior (step by step)

1. **Audit**: list all files at root depth 1, classify each into: KEEP / MOVE / DELETE
2. **Report**: show a triage table with recommended action and rationale for each file
3. **Wait for user confirmation** before doing anything destructive
4. **Execute** only what the user approves — move files to correct folders, delete the rest
5. **Confirm**: show final root state after cleanup

---

## Triage report format

Present findings as a table:

```
ROOT AUDIT — /path/to/workspace
────────────────────────────────────────────────────────
File                              Size    Action    Reason
────────────────────────────────────────────────────────
CLAUDE.md                         9.5K    KEEP      Workspace config
PROJECT-JOURNAL.md               11.5K    KEEP      Workspace log
quinielazo-design-info.json       6.4K    DELETE    Agent analysis leftover
quinielazo-html-info.json         6.3K    DELETE    Agent analysis leftover
quinielazo-links.json             1.4K    DELETE    Agent analysis leftover
quinielazo-accessibility-...      9.7K    DELETE    Agent analysis leftover
quinielazo-style-analysis.json    879B    DELETE    Agent analysis leftover
quinielazo-interactive-...        1.7K    DELETE    Agent analysis leftover
obsidian-local-rest-api.crt       1.2K    DELETE?   Certificate — confirm unused
CHANGELOG.md                      143B    DELETE    Empty autogenerated file
────────────────────────────────────────────────────────
Summary: X to delete · Y to move · Z to keep
```

Then ask: "Proceed with all recommended actions? Or adjust per file?"
